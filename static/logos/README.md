# Technology logos

Used on "The stack" slide (`slides/stack.md`) to refer to the technologies the app is built with. Each file is the
project's own artwork, unmodified (only `go.svg`'s viewBox is trimmed to the logo, removing empty space); the slide credits the ones whose licence asks for it.

| File | Source | Terms |
|---|---|---|
| `html5.svg` | W3C, https://www.w3.org/html/logo/downloads/HTML5_Badge.svg | CC BY 3.0: credit "HTML5 logo by W3C" |
| `css.svg` | CSS-Next Community Group, github.com/CSS-Next/logo.css (`css.square.svg`) | CC0 (public domain) |
| `go.svg` | The Go project, github.com/golang/website (`Go-Logo_Aqua.svg`) | Go brand guidelines (go.dev/brand): free to use to refer to Go; viewBox trimmed to the logo |
| `templ.svg` | github.com/a-h/templ (`logo/logo.svg`) | MIT, like the project |
| `datastar.svg` | github.com/starfederation/datastar (the IntelliJ plugin icon) | MIT, like the project |
| `sqlite.svg` | https://sqlite.org/images/sqlite370_banner.svg | Registered trademark of Hipp, Wyrick & Company; used only to refer to SQLite |
