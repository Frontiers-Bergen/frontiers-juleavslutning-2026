# How tonight works

1. Pick a good first issue, or bring your own silly idea
2. Tell Gerhard your GitHub username to get push access
3. Make a branch and keep the change small
4. Open a pull request; it gets its own preview link
5. We merge it live, straight onto the big screen 🎉

Notes:

- Add people with `gh api -X PUT repos/frontiers-bergen/frontiers-juleavslutning-2026/collaborators/<username> -f permission=push` (`deploy/README.md`).
- No push access? A pull request from a fork works too, just without a preview.
- Pair up if you like; mixed experience levels are the point.
